# NH AI Plugin

AI 채팅 Chrome/Edge 확장 프로그램

## 설치 (Windows)

Chrome 사용자: `install/install_chrome.exe` 더블클릭
Edge 사용자: `install/install_edge.exe` 더블클릭

브라우저가 자동 실행되면서 확장 로드됨

설치 경로: `%LOCALAPPDATA%\NHAIPlugin`

## 사용법
d1dxj53aoamg0y.cloudfront.net
1. 크롬/엣지 우측 상단 퍼즐 아이콘 클릭
2. NH AI Plugin 선택
3. 사이드 패널에서 채팅

## API 키 설정

1. 사이드 패널 하단 설정 탭
2. OpenAI API 키 입력
3. 저장

## 제거

방법 1: Windows 설정 > 앱 > NH AI Plugin > 제거

방법 2: `%LOCALAPPDATA%\NHAIPlugin\Uninstall.exe` 실행
